1. Sign in to your tenant

You sign in with your administrator account to your Microsoft Entra tenant (delegated sign-in, not a shared credential). The Mirage CA Baseline Deployer app is a multi-tenant, public client with no client secret. The first administrator to use it in your tenant sees the standard Microsoft consent screen for the requested Graph permissions.

Account: Not signed in

2. Review what will happen

The baseline covers users, administrators, guests, service accounts, and agents — not every policy applies to every principal on day one.

  • Groups (e.g. BG_BreakGlass, AC_ExcludedFromCA) are created if missing or reused by display name.
  • Named locations ship with placeholder ranges — replace them in Microsoft Entra admin center after deploy.
  • 40 policies: new ones are created in state: disabled (Off). If a policy with the same display name already exists, it is left unchanged (no overwrite of live settings). Re-run is safe.

After deployment

Use Microsoft Entra admin center — not this page — to finish rollout:

  • Open Protection → Conditional Access and review policies (still Off).
  • Update named locations and groups (break glass, exclusions, service accounts) with real values.
  • Enable policies in a controlled order when your runbook says so — optionally use Sign-in logs / Conditional Access insights first.

Full guidance (hosting, roles, fork): see the README — Deploy in your tenant on GitHub.

What this tool does

  • Creates missing Conditional Access policies in Off only; skips policies whose display name already exists (no overwrite). Creates or reuses groups, and creates missing placeholder named locations — using delegated permissions in your session.
  • Does not enable Conditional Access enforcement or set policies to Report-only or On; that remains your decision in Microsoft Entra admin center.
  • Does not use a client secret or application-only permissions; it cannot act without a signed-in administrator.
  • Does not read mail or files; directory access is limited to what Graph needs for groups, locations, and policies.

Source on GitHub — inspect the SPA and baseline JSON before deploying. Graph operations appear in audit logs for the signed-in admin as application Mirage CA Baseline Deployer (application (client) ID 0a54b934-a282-49c8-8e95-eaf7719c9ab2).
